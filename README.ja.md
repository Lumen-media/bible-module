# Bible for Lumen

[Lumen](https://github.com/Lumen-media/lumen) の中で聖書を読み、検索し、映し出せます。ワンクリックで任意の節をプレゼンターに送信 — 礼拝中でもオフラインで全文検索が可能です。

<img width="1602" height="890" alt="聖書の書籍グリッド" src="https://github.com/user-attachments/assets/2daf14e5-5d36-48a3-bda8-19e925357cc9" />

## できること

- **快適に読める** — すっきりした書籍グリッドと、前/次ナビゲーション付きのゆったりした章ビューアで聖書を閲覧。
- **オフライン検索** — 任意の書、章、節へジャンプ、または翻訳の全文を検索 — インターネットは一切不要。
- **節を投影** — 任意の節をプレゼンターへ。大きな読みやすい文字と、書式・背景の完全なカスタマイズ。
- **多数の翻訳** — NAA、ARA、NVI、ARC、ACF、KJV、NIV、NLT、RVR1960 など多数。
- **いつでも使える** — 翻訳はダウンロードしてローカルに保存。接続がなくても聖書はすぐに利用可能。
- **Lumen に調和** — ライト・ダークテーマを含む Lumen の外観に合わせ、ウィンドウ間で自動同期。

## クイックスタート

1. Lumen にモジュールをインストール（**設定 → モジュール → モジュールをインストール**）し、最新リリースの `.lumenpack` を選択します。
2. **ツール** メニューから **Bible** を開きます。
3. 翻訳を選び、書を選んで読み始めましょう — 任意の節をクリックすると投影されます。

### デフォルトの翻訳

初回起動時に、Lumen の言語に応じて 3 つのデフォルト版が自動でダウンロードされます:

| 言語 | デフォルト版 |
|---|---|
| ポルトガル語 (BR/PT) | NAA、ARA、NVI |
| 英語 (米) | KJV、NIV、NLT |
| 英語 (英) | KJV、WEB、YLT |
| スペイン語 | RVR1960、NTV |

他の版は、後でバージョンマネージャーから追加できます。
