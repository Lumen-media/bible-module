# Biblia para Lumen

Lee, busca y proyecta la Biblia desde [Lumen](https://github.com/Lumen-media/lumen). Envía cualquier versículo al presentador con un clic — o busca todo el texto offline mientras el servicio está al aire.

## Lo que hace por ti

- **Lee con comodidad** — Navega la Biblia con una cuadrícula de libros limpia y un lector de capítulos relajado, con navegación anterior/siguiente.
- **Busca offline** — Ve directo a cualquier libro, capítulo o versículo, o busca el texto completo de una traducción — sin internet, nunca.
- **Proyecta versículos** — Envía cualquier versículo al presentador con texto grande, legible y control total sobre tipografía y fondo.
- **Muchas traducciones** — NAA, ARA, NVI, ARC, ACF, KJV, NIV, NLT, RVR1960 y docenas más.
- **Siempre lista** — Las versiones se descargan y se guardan localmente, así que la Biblia está ahí incluso sin conexión.
- **Sigue a Lumen** — Coincide con la apariencia de Lumen, incluidos los temas claro y oscuro, y se mantiene sincronizada entre ventanas.

## Inicio rápido

1. Instala el módulo en Lumen (**Configuración → Módulos → Instalar módulo**) y selecciona el `.lumenpack` de la última versión.
2. Abre **Biblia** desde el menú **Herramientas**.
3. Elige una traducción, selecciona un libro y empieza a leer — haz clic en cualquier versículo para proyectarlo.

### Traducciones predeterminadas

En la primera ejecución, el módulo descarga tres versiones predeterminadas según el idioma de Lumen:

| Idioma | Versiones predeterminadas |
|---|---|
| Portugués (BR/PT) | NAA, ARA, NVI |
| Inglés (EE. UU.) | KJV, NIV, NLT |
| Inglés (GB) | KJV, WEB, YLT |
| Español | RVR1960, NTV |

Añade cualquier otra versión más tarde desde el administrador de versiones.
