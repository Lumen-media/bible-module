# Bíblia para Lumen

Leia, pesquise e projete a Bíblia dentro do [Lumen](https://github.com/Lumen-media/lumen). Envie qualquer versículo para o apresentador com um clique — ou pesquise todo o texto offline enquanto o culto está no ar.

## O que ela faz por você

- **Leia com conforto** — Navegue pela Bíblia por uma grade de livros limpa e um leitor de capítulos tranquilo, com navegação anterior/próximo.
- **Pesquise offline** — Vá direto para qualquer livro, capítulo ou versículo, ou pesquise o texto completo de uma tradução — sem internet, nunca.
- **Projete versículos** — Envie qualquer versículo para o apresentador com texto grande e legível e controle total sobre tipografia e fundo.
- **Muitas traduções** — NAA, ARA, NVI, ARC, ACF, KJV, NIV, NLT, RVR1960 e dezenas de outras.
- **Sempre pronta** — As versões são baixadas e armazenadas localmente; a Bíblia fica disponível mesmo sem conexão.
- **Seguindo o Lumen** — Combina com a aparência do Lumen, incluindo temas claro e escuro, e permanece sincronizada entre janelas.

## Como começar

1. Instale o módulo no Lumen (**Configurações → Módulos → Instalar Módulo**) e selecione o `.lumenpack` da última release.
2. Abra **Bíblia** pelo menu **Ferramentas**.
3. Escolha uma tradução, selecione um livro e comece a ler — clique em qualquer versículo para projetá-lo.

### Traduções padrão

Na primeira execução, o módulo baixa três versões padrão conforme o idioma do Lumen:

| Idioma | Versões padrão |
|---|---|
| Português (BR/PT) | NAA, ARA, NVI |
| Inglês (EUA) | KJV, NIV, NLT |
| Inglês (GB) | KJV, WEB, YLT |
| Espanhol | RVR1960, NTV |

Adicione qualquer outra versão depois pelo gerenciador de versões.
