# Bible for Lumen

Read, search, and project the Bible from inside [Lumen](https://github.com/Lumen-media/lumen). Send any verse to the presenter with one click — or search the whole text offline while the service is on air.

## What it does for you

- **Read comfortably** — Browse the Bible through a clean book grid and a relaxed chapter reader with previous/next navigation.
- **Search offline** — Jump to any book, chapter, or verse, or search the full text of a translation — no internet needed, ever.
- **Project verses** — Send any verse to the presenter with large, readable text and full control over typography and background.
- **Many translations** — NAA, ARA, NVI, ARC, ACF, KJV, NIV, NLT, RVR1960 and dozens more.
- **Always ready** — Versions are downloaded and stored locally, so the Bible is there even without a connection.
- **Follows Lumen** — Matches Lumen's look and feel, including light and dark themes, and stays in sync across windows.

## Quick start

1. Install the module in Lumen (**Settings → Modules → Install Module**) and select the `.lumenpack` from the latest release.
2. Open **Bible** from the **Tools** menu.
3. Pick a translation, choose a book, and start reading — click any verse to project it.

### Default translations

On first run, the module downloads three default versions based on Lumen's language:

| Language | Default versions |
|---|---|
| Portuguese (BR/PT) | NAA, ARA, NVI |
| English (US) | KJV, NIV, NLT |
| English (GB) | KJV, WEB, YLT |
| Spanish | RVR1960, NTV |

Add any other version later from the version manager.
